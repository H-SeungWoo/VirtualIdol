# 가상 공연 플랫폼

## 개요
* 플랫폼 이름
  * STAGE ON
* 설명
  * Unreal Engine 5를 기반으로 개발된 실시간 가상 공연장 플랫폼으로, 스트리머와 팬들이 공연자-관객의 관계로 실시간으로 상호작용할 수 있는 플랫폼.  
* 제작 인원
  * 총 7명 : 기획자 1, 개발자 3, TA 1, BE 1, AI 1
* 프로젝트 기간 
  * 24.10.07-12.19(약 2달)
* 시연 영상 : [Click here to try](https://www.youtube.com/watch?v=JKt8BfGZm_k)

## R(Role) & R(Responsibility) 
### 한승우(XR)
  * 역할
    * 클라이언트 개발자
  * 담당 업무
    * 관객 인터렉션 및 멀티플레이어 구현
    * UI 구조 설계 및 데이터 구현
    * UMG를 활용한 피버타임 연출
    * 음원 재생 시스템 구현
